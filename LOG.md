## Reflection

The most error-prone part of this project was organizing Wiki files and checking internal links.

During the process, some source files were placed in an incorrect folder, and the original Wiki link format did not work properly on GitHub. These problems showed me that even if the content is correct, an incorrect file path or link format can affect the usability of the entire Wiki.

If I could improve the workflow, I would move the file path and link checks earlier. For example, I would test each file and its links immediately after creating it instead of waiting until all Wiki pages were completed.

This experience helped me understand that building a useful knowledge base requires not only organizing information, but also continuously checking its structure and usability.
